# Shopping Program (Java)

A menu-driven console program in Java. The user picks a category, a product and a quantity, and the program displays the total price in AED.

## Features
- Nested switch-case menus for 4 categories (Electronics, Clothing, Books, Groceries)
- 12 products with fixed prices
- Calculates total price from price and quantity
- Shows "Invalid" messages for unknown categories or products

## How to run
1. Install the Java JDK
2. Compile: `javac Shopping.java`
3. Run: `java Shopping`
